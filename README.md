# Personal Budget & Expense Tracker

This project is a static front-end mockup for a personal budget and expense tracker. It demonstrates a clean HTML layout with a summary panel, a form for adding expenses, an expense table, and multimedia content.

## What this project includes

### 1. Budget summary section
The page introduces the tracker with a header and a monthly summary showing income, expenses, and remaining balance.

### 2. Add Expense form
A functional form structure is included with labeled fields for:
- expense name
- amount
- category
- date

The form uses a proper `<form>` wrapper and a submit button with the correct `type="submit"` attribute.

### 3. Expense table
The expense log is presented in a proper HTML table using:
- `<table>`
- `<thead>`
- `<tbody>`
- `<tr>`
- `<th>`
- `<td>`

This creates a readable layout for tracking spending records.

### 4. Multimedia elements
The page includes:
- an `<img>` with `src`, `alt`, `width`, and `height` attributes
- an `<iframe>` embed for a budget-related video

### 5. CSS styling
The stylesheet uses multiple selectors to create a polished layout, including:
- element selectors
- ID selectors
- class selectors
- attribute selectors
- pseudo-class selectors like `:hover` and `:nth-child(even)`

This project serves as the foundation for a larger budget application and shows the structure that will be expanded in later weeks.
